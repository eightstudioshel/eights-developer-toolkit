# Security Policy

## Supported versions

Security fixes are intended for the latest published version. This project is currently in early development.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on this repository when available.

Include a clear description of the affected component and version, reproduction steps, potential impact, and any suggested mitigation. Please allow maintainers reasonable time to investigate before public disclosure.

This project does not collect telemetry or transmit application data.
