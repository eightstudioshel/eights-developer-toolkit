# Code of Conduct

Eights is committed to a welcoming and respectful environment for everyone participating in this project.

## Expected behavior

- Be respectful and considerate.
- Give and receive constructive feedback gracefully.
- Focus on what is best for the community.
- Respect differing opinions and experiences.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, intimidation, and publishing another person's private information without permission are not acceptable.

## Enforcement

Project maintainers may edit or remove comments, reject contributions, or restrict participation when behavior violates this code. Report concerns through the repository's private security contact or maintainer channels.
