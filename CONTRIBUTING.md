# Contributing

Thanks for considering a contribution to Eights Developer Toolkit.

## Local setup

```bash
git clone https://github.com/eightstudioshel/eights-developer-toolkit.git
cd eights-developer-toolkit
npm install
npm run typecheck
npm run build
```

## Pull requests

1. Create a focused feature branch.
2. Follow existing TypeScript conventions.
3. Add or update documentation for public API changes.
4. Run typecheck and build before opening a pull request.
5. Explain the motivation, implementation, and compatibility impact.

For larger changes, open an issue first. Be respectful and constructive in all discussions.
